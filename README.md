# Skill Quest

A 5-minute daily quiz game for ages 12 to 16, by SkillNexus360.

- One file (`index.html`), no server, no sign-up.
- Progress is kept only in the player's own browser; the game collects nothing. The page does load its two fonts from Google Fonts, so the browser contacts Google once when it opens.
- Players can "Add to Home Screen" to get an app icon (`manifest.webmanifest`, `icon-*.png`).

Hosted free on GitHub Pages from the `main` branch.
